# 🔎 Live Search Filter

A simple **Live Search Filter** built with HTML, CSS, and JavaScript.

This project allows users to search through a list of fruits in real time. The results update automatically as the user types.

## 🚀 Features

* 🔍 Real-time search
* ⚡ Instant filtering while typing
* 🔤 Case-insensitive search
* 📋 Displays multiple matching results
* 🧹 Clears previous results before displaying new ones
* 🌐 Built with vanilla JavaScript — no frameworks

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* Array `filter()`
* `includes()`
* `forEach()`
* `addEventListener()`

## 🧠 What I Learned

Through this project, I practiced:

* Selecting HTML elements using `getElementById()`
* Handling the `input` event
* Getting user input using `.value`
* Filtering arrays using `filter()`
* Searching strings using `includes()`
* Converting text to lowercase using `toLowerCase()`
* Creating HTML elements dynamically using `createElement()`
* Updating elements using `textContent`
* Adding elements to the DOM using `appendChild()`
* Clearing dynamic content using `innerHTML`

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start typing a fruit name in the search box.

## 💡 Example

Searching for:

```text
an
```

will display:

```text
Banana
Mango
Orange
```
